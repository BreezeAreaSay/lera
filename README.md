# Попчик 💛

Личный мессенджер для Леры и Лёши — подарок на день рождения (26 лет, 15 сентября).

**Живой сайт:** https://addabbs.github.io/popchik/

## Что внутри

Один файл `index.html` — веб-приложение в стиле Телеграма с тёплой летней палитрой:

- **Вход по кодовому слову** («Попчик») + экран-приветствие с шуткой про «свой мессенджер».
- **Чат** — переписка с реакциями «Попчик / Припопка / Отпопка».
- **Планы** — общий чек-лист того, что сделать вместе.
- **Желания** — общий вишлист.
- **Воспоминания** — фотогалерея, фото добавляются прямо на сайте (сжимаются в браузере).

## Хостинг

Развёрнуто через **GitHub Pages** из отдельного репозитория `addabbs/popchik`
(владелец — личный аккаунт Леры), не через этот репозиторий и не через
хостинг Claude-артефактов — тот оказался ненадёжен из этой сессии
(артефакты `claude.ai/code/artifact/...` стабильно не загружались:
проверено на трёх разных ссылках). Сайт полностью независим от Клода:
открывается в любом браузере, на любом устройстве, без входа в какой-либо
аккаунт.

**Процесс обновления:** правки вносятся здесь (в этом репозитории,
`index.html`), затем файл отправляется Лере, и она вручную перезаливает
его на странице `addabbs/popchik` (Add file → Upload files → Commit) —
GitHub Pages подхватывает изменения автоматически через 1-2 минуты.

## Текущее ограничение — нет синхронизации между устройствами

Сообщения/планы/желания/фото сохраняются в `localStorage` **каждого
устройства отдельно** — то, что добавлено на одном телефоне, не появляется
само на другом. Для настоящей живой синхронизации между Лерой и Лёшей
нужен небольшой бесплатный сервис (например, Firebase) — это следующий
возможный шаг, если Лера захочет.

## Технические детали

- Один HTML-файл, без сборки и внешних зависимостей (даже шрифты — системные,
  внешний Google Fonts был убран: вызывал зависание загрузки в некоторых
  средах рендеринга артефактов).
- Идентификация «Лера / Лёша» хранится в `localStorage` устройства (без аккаунтов).
- Фото сжимаются в браузере перед сохранением (~200-250 КБ на фото).
