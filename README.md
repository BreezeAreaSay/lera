# Попчик 💛

Личный мессенджер для Леры и Лёши — подарок на день рождения (26 лет, 15 сентября).

## Что внутри

Один файл `index.html` — веб-приложение в стиле Телеграма с тёплой летней палитрой:

- **Вход по кодовому слову** + экран-приветствие с шуткой про «свой мессенджер».
- **Чат** — переписка с реакциями «Попчик / Припопка / Отпопка».
- **Планы** — общий чек-лист того, что сделать вместе.
- **Желания** — общий вишлист.
- **Воспоминания** — фотогалерея, фото добавляются прямо на сайте.

Все данные (сообщения, планы, желания, фото) хранятся в общей базе артефакта Claude
(`db` capability) и видны обоим сразу, без отдельного сервера.

## Как открыть

Файл опубликован как приватный Claude Artifact — ссылку и доступ Лера выдаёт вручную
через меню «поделиться» на странице артефакта.

## Технические детали

- Один HTML-файл, без сборки и зависимостей (кроме шрифтов Google Fonts).
- Идентификация «Лера / Лёша» хранится в `localStorage` устройства (без аккаунтов).
- Фото сжимаются в браузере перед сохранением (лимит ~250 КБ на документ).
